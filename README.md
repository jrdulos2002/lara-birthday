# Lara's Birthday Website 🎂

An interactive, cinematic birthday experience in a single self-contained HTML file.

## The Experience
1. Tap the sign to begin — swipe the curtains open
2. Pop all the balloons
3. Drag the lit lighter to each candle of the "25"
4. Tap the cake to blow — it explodes!
5. The splatter wipes away to reveal an envelope — open the letter
6. Fold the letter back and the cat pounces, scattering the envelope
7. Catch the parachute gift box and tap it — music box Happy Birthday + photo film strips

## Run It
Just open `index.html` in any browser (works great on mobile). No server or dependencies needed — all 8 photos are baked in.

## Hosting (optional)
Drop `index.html` on [Netlify Drop](https://app.netlify.com/drop) for a shareable link.
